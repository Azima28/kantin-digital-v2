# Bright Text for Dark Mode
## Antigravity AI - Gemini 3.5 Flash (Medium)

---

# Objective

Update the application's Dark Mode typography so that every text element uses bright, high-contrast colors for maximum readability and accessibility.

Do not modify layouts, components, spacing, animations, navigation, or business logic.

Only improve text visibility in Dark Mode.

---

# Global Rule

Every text element displayed in Dark Mode MUST use bright colors.

Never use dark-colored text.

Never use low-contrast gray text.

Never allow text to blend into the background.

All typography must remain highly readable in every screen.

# Accessibility Rules

Maintain WCAG AA minimum contrast.

Prefer WCAG AAA whenever possible.

Every title must remain immediately readable.

Every paragraph must have sufficient contrast.

Never reduce readability for aesthetics.

---

# Things to Avoid

Do not use black text.

Do not use dark gray text.

Do not use low-opacity white for important text.

Do not hide text against dark backgrounds.

Do not use decorative typography that reduces readability.

---

# Expected Result

Every title, heading, label, paragraph, button text, navigation label, dialog title, popup title, form label, placeholder, table text, notification text, and every other typography element across the entire application must automatically switch to bright colors when Dark Mode is active, providing a modern, premium, highly readable, and fully accessible user experience.
