* Flat black backgrounds
* Flat gray everywhere

# GLASSMORPHISM

Glass effect should be subtle.

Use:

* Backdrop Blur
* Semi-transparent surfaces
* Thin borders
* Soft highlights

Avoid excessive transparency.

---

# DECORATIVE ELEMENTS

The UI should never feel empty.

Use subtle decorative elements:

* Soft gradients
* Accent glow
* Floating shapes
* Tiny geometric patterns
* Decorative divider lines
* Blurred light spots
* Gradient overlays
* Accent corner highlights
* Glass reflections
* Soft background mesh gradients

Keep decorative elements below 10% visual prominence.

They should enhance the interface, not distract users.

---

# CARD DESIGN

Cards should feel premium.

Use:

* Rounded corners
* Layered backgrounds
* Soft gradients
* Thin borders
* Diffuse shadows

Avoid flat rectangles.

150-250ms

* Button lift
* Card elevation
* Ripple
* Toggle slide
* Smooth fade
* Scale
* Slide

* Success check animation

---

# VISUAL HIERARCHY

Guide the user's eyes naturally.

Priority:

1. Primary Action

2. Important Information

3. Supporting Information

4. Secondary Content

Use:

* Size
* Color
* Spacing
* Elevation

Avoid excessive decoration.

# EMPTY STATE

Never leave blank pages.

Include:

* Friendly illustration
* Short message
* Helpful description
* Primary action button

---

# LOADING STATE

Always use skeleton loading.

Avoid large spinning loaders.

---

# ERROR STATE

Provide:

* Clear explanation
* Suggested solution
* Retry button

Never blame the user.

---

# SUCCESS STATE

Use:

* Check icon
* Soft animation
* Positive color
* Clear confirmation

---

# ACCESSIBILITY

Follow WCAG 2.2.

Ensure:

* High contrast
* Readable typography
* Touch target ≥ 44px
* Keyboard support
* Focus indicators
* Color-blind friendly palettes

Accessibility is mandatory.

---

* Android

# CONSISTENCY RULES

Every page must automatically inherit:

* Color palette
* Typography
* Radius
* Shadows
* Motion
* Components
* Icons
* Navigation
* Spacing

Do not introduce a different visual style unless explicitly requested.

---

# FORBIDDEN DESIGN

Avoid:

* Pure black backgrounds
* Low contrast
* Tiny text
* Hard shadows
* Excessive gradients
* Heavy glass effects
* Neon colors
* Random spacing
* Inconsistent icons
* Crowded layouts
* Flat lifeless cards

---

# QUALITY CHECK

Before generating the final design, review:

* Is the hierarchy clear?
* Is the contrast readable?
* Is the spacing balanced?
* Are the colors consistent?
* Does the interface feel premium?
* Is every interaction intuitive?
* Does the UI reduce eye fatigue?
* Are decorative elements subtle and purposeful?

If any answer is "No", refine the design before presenting it.

---

# FINAL REQUIREMENT

Every screen generated from this Design System must feel like part of one polished, premium product.

The design should never look generic or monotonous.

Introduce tasteful visual interest through soft gradients, layered surfaces, elegant lighting, restrained decorative elements, and smooth motion while preserving simplicity, readability, and usability.

Design every page as if it will be used daily by thousands of users for long periods, prioritizing comfort, consistency, accessibility, and a premium user experience.
