# 🌙 Universal Dark Mode Design System
## AI Design Instruction for Antigravity Model AI (Claude Sonnet 4.6 Thinking)

---

# Objective

Transform the entire application into a modern, premium, elegant, highly readable, and visually consistent Dark Mode interface without changing any business logic, workflow, navigation structure, feature behavior, interaction flow, or information architecture.

Dark Mode must improve visual comfort, readability, accessibility, and premium appearance while maintaining all existing functionality.

Every screen, page, modal, popup, dialog, bottom sheet, navigation, form, dashboard, table, chart, notification, loading state, empty state, error state, success state, animation, and every user role must automatically follow this Dark Mode Design System.
